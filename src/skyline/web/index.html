Get real data from the public alert broker

Skyline starts with an alert broker, not a private telescope feed. Choose a UTC observation date; the helper turns it into the Modified Julian Date (MJD) required by the download command.

  1. Run the download command in the Skyline project folder.
  2. Run make real-tonight to rank the saved real alerts.
  3. Restart make dashboard with the real alert paths if you want this page to display that batch.

Each download writes a local receipt with source, date range, row count, and retrieval time. The data stays on your machine and is excluded from Git.
